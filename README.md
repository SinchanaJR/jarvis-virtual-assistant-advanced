# Jarvis Virtual Assistant — Advanced

A polished browser-based virtual assistant demo built with **Python, Flask, HTML, CSS, and JavaScript**. It includes a chat UI, browser speech recognition (where supported), spoken responses, quick commands, safe arithmetic, and limited website-opening commands.

## Features

- Responsive futuristic dashboard
- Chat interface with quick prompts
- Flask JSON API (`POST /api/chat`)
- Browser voice input using the Web Speech API where supported
- Text-to-speech using browser speech synthesis
- Date and time responses
- Basic arithmetic without `eval()`
- Supported website shortcuts: Google, YouTube, GitHub, Gmail, Wikipedia
- Health endpoint (`GET /api/health`)
- No paid API key required

## Requirements

- Python 3.10+
- A modern browser (Chrome or Edge recommended for speech recognition)

## Run on Windows

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
$env:SECRET_KEY = python -c "import secrets; print(secrets.token_hex(32))"
python app.py
```

Open `http://127.0.0.1:5000`.

## Run on macOS/Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export SECRET_KEY="$(python -c 'import secrets; print(secrets.token_hex(32))')"
python app.py
```

Then open `http://127.0.0.1:5000`.

## Notes and limitations

- This is an educational demo, not a general-purpose AI model. Replies are generated by local rules.
- Voice recognition availability depends on browser support and permissions; some browsers may use their own speech service.
- Website-opening commands open a new browser tab only for a small allowlist.
- The app does not connect to bank accounts, email accounts, or private data.
- Before public deployment, configure a strong secret key, turn off debug mode, add production hosting/security controls, and review privacy requirements.
